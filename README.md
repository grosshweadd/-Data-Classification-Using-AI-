# Data Classification Using AI

## Overview

This project demonstrates a basic machine learning classification model using the Iris dataset. A Decision Tree Classifier is used to classify flower species based on their measurements.

## Objective

The objective of this project is to understand the fundamentals of supervised machine learning by training and testing a classification model.

## Dataset

The Iris dataset contains 150 samples of iris flowers belonging to three species:

- Setosa
- Versicolor
- Virginica

The dataset includes:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Algorithm Used

Decision Tree Classifier

## Technologies Used

- Python
- Scikit-Learn

## Features

- Load and analyze the Iris dataset
- Split data into training and testing sets
- Train a Decision Tree model
- Predict flower species
- Evaluate model accuracy

## How to Run

1. Install required libraries:

   pip install scikit-learn

2. Run the program:

   python classification.py

## Output

The program displays:

- Dataset information
- Training and testing sample counts
- Model accuracy
- Sample predictions

## Learning Outcome

This project helped in understanding data preprocessing, model training, prediction, and evaluation using machine learning techniques
